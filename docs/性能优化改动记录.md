    - **`lib/chat-storage.ts`**：`normalizeLegacyTextToolHistory` 开头加 O(N) 快速短路——先用一次 `messages.some(...)` 判断是否真的存在旧版 `tool_result` / `tool_notice` 痕迹，没有就直接 `return { items: messages, changedMessages: [] }`。原实现外层遍历全库、内层对每条消息再做两次 `sorted.map().filter()` 全表扫描，是标准 O(N²)；5000 条消息即数千万次迭代，且完全同步执行，冷启动后第一次碰聊天数据（自定义 APP 首个 bridge 请求触发的 `hydrateChatStorage`）就把主线程锁死，移动端直接被系统杀掉。这是「打开自定义 APP 闪退」的第一重根因。
