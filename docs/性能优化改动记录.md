## 二、 iOS Safari 防卡顿与防闪退当前实际生效代码（共 28 个文件）

### A. 聊天记录会话缓存与渲染元数据预计算（防高频数组分配与 OOM 闪退）
1. `lib/chat-storage.ts`：
   - **会话排序结果缓存**：在 `messagePositionsBySession` 之上维护 `const _sortedSessionCache = new Map<string, ChatMessage[]>()`；`getSortedSessionMessages(sessionId)` 命中缓存直接返回，并在 `pushChatMessage` / `upsertImportedChatMessage` 中调用 `appendToSessionBucket`（用 `[...cached, msg]` 不可变追加），在 `editChatMessage` / `retractChatMessage` / `updateMessageMediaStatus` / `updateMessageMediaData` / `updateMessageMediaUrl` / `persistMessageVoiceAudio` / `updateChatMessage` 中调用 `replaceInSessionBucket` 不可变替换，删除/重排时调用 `invalidateSessionMemo`。
   - **头像推荐倒序窗口查找**：`resolvePendingAvatarRecommendation` 对 `getSortedSessionMessages(message.sessionId)` 从尾部倒序最多查 48 条，不拷贝全表 `_messagesCache`。
   - **最新状态值按会话尾部查找**：`getLatestCharacterStateValues` 仅遍历该角色参与的会话，从各会话 `getSortedSessionMessages(s.id)` 尾部倒序找第一条带 `stateValues` 的消息。
2. `lib/chat-avatar-intent.ts`：
   - `findUserAvatarChangeIntent` 先截取 `const tailWindow = history.length > 48 ? history.slice(-48) : history;` 再过滤。
3. `components/chat/chat-room.tsx`：
   - **点击生成首帧绘制让出**：`runManagedGeneration` 与 `triggerAIResponse` 在 `setIsGenerating(true)` 后均执行 `await new Promise<void>(resolve => requestAnimationFrame(() => { setTimeout(resolve, 0); }));`，先让按钮切换出「生成中」状态再装配上下文。
   - **气泡渲染元数据预计算**：`projectedMessageRenderMeta`（`useMemo`）一次遍历算出 `displayContents`、`hiddenFlags`、`prevVisibleMessages`，气泡渲染循环直接按索引读取。
   - **双聊天室同时生成隐藏态静默**：全部 6 处 `onStreamDelta` / `onOfflineDelta` 在累加 `streamAccumRef.current += delta` 后判断 `if (!isChatRoomElementVisible(wrapperRef.current)) return;`，隐藏聊天室不触发 `setStreamPreview` 重渲染。
   - **切后台跳过 800ms 延迟立即落库**：`splitAndSaveAIMessages` 中若 `document.visibilityState === "hidden"` 或 `!isChatRoomElementVisible(wrapperRef.current)`，跳过 `abortableDelay(800)` 直接调用 `publishVisibleMessage` 落库。
   - **进聊天室按需预热表情包**：仅提取当前可见 `msgs`（30 条）中的 `sticker` 名称集合传给 `prewarmStickerCache(id, usedStickerNames)`。
4. `components/chat/chat-settings-panel.tsx`：
   - `ChatSettingsPanel` 使用 `memo(...)` 包裹（比较 `prev.session === next.session && prev.offlineHistoryBusy === next.offlineHistoryBusy`）。

### D. 切后台防强杀重启、后台保活防 OOM、防黑屏与离线预约同步及时间戳保真
21. `lib/bg-timer.ts`、`lib/use-weixin-bridge.ts`、`lib/moments-engine.ts`、`lib/diary-entry-timer-service.ts`：
    - `bg-timer.ts`：维护 `intervalIds` 集合，仅在 `document.visibilityState === "hidden"` **且未开启后台保活（`!isKeepAliveEnabled()`）** 时跳过 `bgSetInterval` 回调；若用户开启了后台保活则照常运行；
    - `moments-engine.ts`（`pollPendingReactions`）与 `diary-entry-timer-service.ts`（`runDiaryEntryTimerCheck`）：在 `document.visibilityState === "hidden"` 时跳过朋友圈后台发帖/识图互动与定时日记生成，留到回前台再触发，防止后台保活期间解码大图与组装巨型 Prompt 触发 iOS Jetsam 强杀；

22. `lib/timed-wake-storage.ts`、`lib/push-bailout-client.ts`、`lib/push-bridge-sync.ts`（根治切后台被系统强杀重启 + 离线预约漏同步与 413 失败）：
    - `installScheduledBailoutRefresher` 与 `installBridgeServerSync` **严禁在 `if (document.hidden)` 切后台瞬间调用 `refreshScheduledBailouts()` / `runSync()` 全量组装多个角色的 Prompt 快照**，且 `runSync()` 入口带 `if (document.hidden) return;` 守卫防止 3 秒防抖定时器在切入后台后触发组装；
    - `timed-wake-storage.ts` 的 `saveTimedWakeSchedules` 保存后派发 `timed-wake-schedules-updated` 事件，`push-bailout-client.ts` 监听该事件并在前台防抖调用 `refreshScheduledBailouts()`，确保聊天中 AI 或用户创建的定时唤醒在前台即刻同步到云端；
    - `push-bailout-client.ts` 对携带 `shortcutContinuation` 的双份 Prompt 增加体积守卫（`trimContinuationIfOversized`，超过 650KB 自动剥离第二轮 `shortcutContinuation` 降级为单轮推送），防止触发云端 900KB 限制返回 413 导致整个离线预约静默失败。
23. `lib/bg-tone.ts` & `components/desktop-shell.tsx`（根治从后台切回时黑屏且不触发整屏 GPU OOM）：
    - `bg-tone.ts`：`sampleImageColor` 在 `finally` 中置 `canvas.width = 0; canvas.height = 0;` 释放 WebKit Canvas GPU 内存；
    - `desktop-shell.tsx`：监听 `visibilitychange` 与 `pageshow`，从后台回到前台时**仅对轻量状态栏 `.status-bar` 做一次 `opacity: 0.999` → `rAF` 复位唤醒重绘**（严禁对整棵 `.phone-shell` 根容器设置 `translateZ(0)`，否则 WebKit 会为全屏所有子元素重建巨幅 GPU 合成纹理，导致切回前台瞬间 Jetsam 闪退）。
24. `lib/chat-engine.ts`、`lib/memory-summarizer.ts`、`lib/push-outbox-client.ts`、`lib/follow-up-service.ts`：
    - `push-bailout-client.ts` 导出 `canArmReplyBailout()`；`chat-engine.ts` 在生成第 6 秒先预检通过才拷贝 `llmMessages` 并构建请求；`rasterizeImageBlobToJpegDataUrl` 在 `finally` 中置 `canvas.width = 0; canvas.height = 0;`；`fetchRemoteImageBlob` 带 8 秒超时；生成结束后延迟 6 秒触发 `maybeRunSummarization`；
